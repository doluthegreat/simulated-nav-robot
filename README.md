# Simulated Autonomous Navigation Robot

An ongoing ROS 2 and Gazebo simulation project exploring mobile robot localization, sensor integration, and autonomous navigation pipelines.

## Roadmap & Future Plans
- [ ] **Phase 1:** Set up differential-drive robot URDF model and Gazebo world environment.
- [ ] **Phase 2:** Integrate simulated range/LiDAR sensors and publish raw scan data via ROS 2 topics.
- [ ] **Phase 3:** Implement Monte Carlo Localization (AMCL / custom particle filter) for noisy sensor pose estimation.
- [ ] **Phase 4:** Develop a reactive local path planner and obstacle avoidance behavior tree.
